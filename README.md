Welcome to my personal portfolio website built with **Next.js and React**.

## ✨ About the Project

This is a personal portfolio website created to present my technical skills and projects in a clean and modern interface.

The website is built using **Next.js App Router** and follows a component-based structure with reusable Header and Footer components.
